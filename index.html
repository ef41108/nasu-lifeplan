共有URLで開く使い方

GitHub PagesやNetlifyなどに index.html と data.json を置くと、夫婦それぞれのスマホ・PCブラウザから同じURLで開けます。index.htmlは固定し、毎月の最新値は data.json を差し替えて反映します。
妻の使い方
スマホでホーム確認、シミュレーション、手動イベント追加を使います。
夫の使い方
PCで月次更新を行い、更新後のdata.jsonを差し替えます。
URL共有の注意
家計・資産情報を含むため、完全公開URLではなく、共有範囲を限定して扱ってください。

Ver4.0 運用メモ
Ver4.0では、アプリ本体の index.html と毎月更新データの data.json を分離します。共有URL運用では index.html は基本的に固定し、夫が月次更新後に data.json だけを書き出して差し替えます。
読み込み元：確認中
バージョン情報を確認中です。
公開範囲の注意
data.json には家計・資産情報が含まれます。完全公開URLや第三者が見られる場所への配置は避け、共有範囲を夫婦内に限定してください。ログイン機能・自動ログイン連携・金融機関ID/パスワード管理は行いません。
data.jsonを読み込む
同じフォルダの data.json は起動時に自動読込します。手元のファイルを指定して読み込むこともできます。
data.jsonを書き出す
月次更新後はこのボタンで data.json を保存し、共有URL側の data.json と差し替えます。
